# Hearthstone HUD v1.0.6

## Cross-display hover fix / 跨 Display 悬停修复

The v1.0.5 diagnostic confirmed seven registered arena card regions while 2138
pointer samples stayed at (1919,1079). Hearthstone used X11 :1 and the HUD rendered
on :0, so querying the HUD server did not observe movement over the game.

v1.0.5 诊断显示竞技场 7 个卡牌区域均已注册，但 2138 次鼠标采样始终为右下角
(1919,1079)。游戏使用 :1，HUD 使用 :0，读取 HUD 侧指针没有观测到游戏中的移动。

- Pass the live game's validated local DISPLAY through state.json. For different
  displays, read the game pointer through an independent read-only XCB connection
  and map game-root coordinates into the fullscreen HUD display space.
  将游戏的本地 DISPLAY 传入渲染器；Display 不同时，通过独立只读 XCB 连接读取游戏鼠标并映射到 HUD。
- Keep rendering on the original HUD display; preserve empty X11 input shape,
  ImGui NoInputs, shared card registration, downloads and image caches.
  HUD 仍在原 Display 渲染；点击穿透、卡牌注册、下载及缓存不变。
- Report source display, source resolution, mapping mode and connection errors.
  Close the game connection when changing sources or shutting down. Connection
  failures are retried after five seconds and never silently use the wrong pointer.
  诊断记录来源 Display、分辨率、映射方式和连接错误；来源变化或退出时释放连接，失败冷却五秒重试。
- Same-display setups retain the existing overlay-client conversion path. Cross-
  display mapping assumes the game root covers the fullscreen overlay output;
  compositor letterboxing/cropping remains a live-device verification case.
  相同 Display 保留原客户区转换；跨 Display 映射以全屏输出对应为前提，特殊黑边或裁剪需实机确认。

## Validation / 验证

18 targeted Python tests passed, including game-display state propagation without
moving the overlay, input validation, diagnostics, downloads and lifecycle checks.
Native display-selection, schema and scaled-coordinate regression cases were added
for CI. No local build, packaging or build-environment installation was performed.
Linux/SteamOS hover behavior remains unverified. GitHub Actions builds/tests/packages
this tag, including the libxcb development dependency.

18 项针对性 Python 测试通过；已补充原生 Display 选择、状态校验和缩放映射测试供 CI 执行。
未在本地构建、打包或安装环境；Linux/SteamOS 实机悬停仍待验证。
