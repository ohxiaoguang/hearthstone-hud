# Hearthstone HUD v1.0.2

A small robustness release for the card-art download queues introduced in
v1.0.1's follow-up work. No new features.
针对 v1.0.1 后加入的卡图下载队列的稳健性修复，无新功能。

## Fixes / 修复

- **Promotion respects the queue capacity.** When the game requests a card that is waiting
  in the bulk-download queue, the plugin moves it to the front — but now it checks the
  on-demand queue's capacity first. When that queue is full, the card keeps its
  low-priority slot and its pending reservation: no `queue.Full` error, no lost download
  task, and the promotion is simply retried on a later request.
  **提升操作尊重队列容量**：游戏请求仍在批量队列中的卡图时，会先检查高优先级队列是否已满。
  已满时该卡保留在低优先级队列与待处理状态中——不会抛出 `queue.Full` 异常，不会丢失下载
  任务，稍后的请求会再次尝试提升。
- **One download per card, in every path.** The existing guarantees are covered by tests:
  a promoted card is fetched exactly once and counted once; the whole batch completes with
  one download per card even after promotions from a saturated queue; cancelling the batch
  keeps already-downloaded tiles, drops the rest, and a card promoted before the cancel
  still downloads as the game request it became.
  **每张卡在所有路径下都只下载一次**：已有测试覆盖——提升的卡只下载一次并只计一次；即使从
  满载队列发生提升，整批依然每卡恰一次；取消批量保留已下载卡图、清除剩余任务，取消前已
  提升的卡图仍会作为游戏请求完成下载。
- The two queue-capacity and cancel-interaction edge cases are now covered by dedicated
  regression tests.
  新增针对"队列满载下的提升"与"取消与提升交互"的专项回归测试。

## Verification / 验证

- Python: 230 unit tests pass, including the new promotion-capacity and
  cancel-after-promotion cases.
- Frontend: TypeScript type check, build and panel checks pass; both interface dictionaries
  carry the same keys.
- Native: HUD state tests and the Linux renderer (Ubuntu 20.04, glibc 2.31) build in CI;
  ZIP packaging and packaged-module import check run on every build.

## Install / 安装

Stable address, always the newest version:
固定地址，始终为最新稳定版：

```
https://github.com/ohxiaoguang/hearthstone-hud/releases/latest/download/hearthstone-hud.zip
```

Or grab `hearthstone-hud.zip` from this release page, then in Decky Loader open
**Settings (⚙) → General → Install plugin from file** and pick the ZIP. Upgrading keeps
settings, caches and card art.

或在本 Release 页面下载 `hearthstone-hud.zip`，在 Decky Loader 中打开
**设置（⚙）→ 通用 → 从文件安装插件** 选择该 ZIP。覆盖升级保留设置、缓存与卡图。
