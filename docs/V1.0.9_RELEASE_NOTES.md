# Hearthstone HUD v1.0.9

## Arena data updates / 竞技场数据自动更新

- The HUD starts with local arena data and checks for newer HearthArena card ratings
  and Firestone class statistics in the background. Changed files are verified and applied
  separately, with local snapshots available offline.
  HUD 启动时先读取本地快照，在后台检查 HearthArena 卡牌评分和 Firestone 职业统计。
  变化的文件分别下载、校验和应用，离线时继续使用本地数据。
- Automatic checks run on first launch and every 24 hours from the latest check.
  An overdue check runs after sleep or restart. **Check for updates now** starts a new
  24-hour interval and is available with automatic updates turned off.
  首次启动立即检查，之后从最近一次检查起每隔 24 小时检查。休眠恢复或重启后补检已到期的更新。
  「立即检查更新」会重新计时，关闭自动更新后仍可使用。
- Open **Arena data** in Decky settings to see the sources, dates and update status.
  Normal and Underground Arena have separate class statistics and source dates.
  在 Decky 设置的「竞技场数据」中可查看来源、日期和更新状态。
  普通竞技场与地下竞技场各自显示职业统计的上游日期。
