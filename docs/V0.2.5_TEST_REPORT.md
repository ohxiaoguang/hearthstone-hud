# v0.2.5 牌库模型专项修复

## 数据规则

`own` 有 Decks.log 时只来自初始牌组定义，保存 initial 与 remaining；未知 dbfId 保留未知行。没有 Decks 定义时只展示确认为原始牌的实体身份，数量为已知在库下限，不虚构完整牌组。原牌实体离开己方 DECK 即扣减；HAND→PLAY/SECRET 不再次扣减；原牌洗回恢复；在库变形身份移入独立区域。单张未知不影响已完全解释的其他原牌。非原始牌库实体的身份未知也不再污染原牌数量。

`own_added` 仅投影当前己方 DECK 中的非原始身份实体，按 CardID、来源类别、来源实体分组。生成到手牌/场上以及已打出的牌不在其中；离开 DECK 同步移除。同 CardID 的初始牌与额外牌从不合并剩余量。

`own_played` / `opponent_played` 只记录真实 HAND→PLAY/SECRET 转移，保存 card_id、中文名称、回合、原始半回合、顺序、实体、控制者、原牌身份、生成/外来证据、回手状态、洗入历史及可知来源 ID/名称。每次出牌单独保存，重复 ZONE=PLAY 不新增，回手再打新增。身份快照不被后续变形改写；未揭示的旧出牌不能靠变形后的身份补全。已知身份在 SHOW 后可补全。记录与牌库计算互不依赖。

`opponent_seen` 按公开实体/身份去重，包含公开但未打出的牌，与实际出牌事件分开。旧 `opponent` 字段保留兼容公开视图。

## 来源证据与边界

- 初始：实体 setup 时处于 DECK，并记录原 owner；控制者改变时识别对手获得。
- 效果生成：非原始实体创建时活动 BLOCK 的来源实体，或明确 CREATOR / DISPLAYED_CREATOR 标签；保存创建来源身份避免来源随后变形造成误标。
- 复制：明确 COPIED_FROM_ENTITY_ID。该标签的实际客户端覆盖率尚未实机验证。
- 回手：arrival 的来源区域为 PLAY / SECRET / GRAVEYARD，独立标志，不改变初始牌身份。
- 洗入：实际观测到 DECK 区域，仅当前仍在库计数量，不凭“生成过”推断。
- 变形：原始实体当前 CardID 与 first_card_id 不同，保留原实体来源并标记变形。
- 未证明来源：显示“非初始牌组”或“来源未知”；generated=false 表示无生成证据，不证明其绝非生成牌。发现和普通生成不能只靠 Power 区域转移可靠区分，因此没有证据不标“发现”，也不根据卡牌名称猜来源。

分类参考 [hs-decktracker-linux tracker.py](https://github.com/justfaked/hs-decktracker-linux/blob/main/decktracker/tracker.py) 的牌库/plays 分离，以及 [Deste](https://github.com/yusufipk/deste-hearthstone-linux-tracker) 的原牌保留淡化与卡图底图。不接入这些项目的内存或其他功能。

## 定向验收

以下均为自动化日志格式/合成样本验证，不是 Ally X 实机确认：

| 场景 | 结果 |
| --- | --- |
| 1. 两份同名原牌 | 初始 2，保留一行 |
| 2. 抽走一份 | 剩余 1 |
| 3. 打出不重复扣减 | 仍剩余 1，新增出牌事件 |
| 4. 手中/场上生成牌 | 不进入 own / own_added |
| 5. 生成牌实际打出 | 只新增 own_played；原牌量不变 |
| 6. 生成牌洗入 | 当前在库才计 own_added |
| 7. 抽出洗入牌 | own_added 同步移除 |
| 8. 生成牌与原牌同 CardID | 独立实体、独立数量、保留来源 |
| 9. 复制/变形/回手/洗回 | 来源分组、快照不变、重打新增、洗回恢复 |
| 10. 对手 seen / played | 公开未出牌只有 seen，实际出牌另记 |
| 11. 同一牌重复打出 | 保留两次事件和顺序 |
| 12. 重连/重复日志/新局 | 快照回放不新增出牌；重复行忽略；新局清空 |
| 13. 局部身份未知 | 不影响其他已解释原牌；未知额外实体单列 |
| 14. 隐藏牌后续变形 | 不把变形身份虚构为先前出牌身份 |
| 15. SSL 测试开关 | 数据库/卡图独立；JSON 无效不替换缓存 |

本地：70 项 Python 测试通过；含最终 ZIP 解压后隔离 Python import 测试（测试 ELF 占位仅用于打包结构验收，不作为安装产物）。Python 语法、TypeScript 类型检查、前端构建、剪贴板 4 路径与 Decky 展开控件检查通过。

Linux 原生编译与 C++ HUD 状态/新区域校验由 Actions 执行；安装资产必须通过 ELF x86_64、ldd、readelf/GLIBC <=2.31 及最终 ZIP 导入检查才交付。

## 实机未验证

没有收到可回放的真实 Ally X 原始 Power/Decks 日志。本次使用已确认语法的脱敏/合成格式样本（`tests/fixtures/power-format.txt`）及带 BLOCK、SHOW、CHANGE、ZONE 事件的合成日志；它们不代表真实对局覆盖率。发现来源、复杂跨方复制、异常重连/超过去重窗口的旧日志回放及新底图布局的实机表现尚未验证。去重窗口沿用最近 8192 条完整时间戳行；不宣称能去重任意长度历史重放。

Gamescope/X11 窗口属性、输入形状、焦点、触控穿透及 Overlay 协议不变。只修改 HUD 内容绘制、模型和 SSL 测试选项。用户安装后请用正常对局检查同名生成、洗入与回手重打，不需要在 SteamOS 安装任何开发工具。
