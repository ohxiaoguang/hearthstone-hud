# Hearthstone HUD v0.7.2

Release hardening for the resource-management panel of v0.7.1. No new features.
v0.7.1 资源管理面板的发版加固，无新功能。

## Fixes / 修复

- **Each card is counted once.** A card that fails and then succeeds on the retry is
  reported as a success only; only a card that fails both attempts counts as failed.
  The progress bar derives "finished" from the final counters and is clamped to the
  batch size, so it can never exceed 100%.
- **No art is not a failure.** A Card ID the art server answers HTTP 404 for is
  counted separately as *without art*, is never retried, does not appear in the error
  list, and is not requested again in the same session — neither by a second full
  download nor by the on-demand requests for cards on screen.
- **The legacy `images/manual/` cache is no longer invisible.** Image statistics count
  PNG files in both the current cache and the legacy manual directory, and
  *Delete card art* removes both — only PNG files, leaving card databases, settings
  and any other files untouched.
- **Accurate final summary.** While the batch runs the panel shows finished/total with
  failure and no-art counts; when it completes, a final summary lists downloaded,
  failed, without-art and already-cached cards.

- **每张卡只计一次**：首次失败、重试成功的只记成功；两次都失败的才记失败。进度条的
  「已完成」由最终结果派生并钳制在批量总数内，不会超过 100%。
- **无卡图不算失败**：服务器对该 Card ID 返回 HTTP 404 时单独计为「无卡图」，不重试、
  不进错误列表，同一会话内不再请求——再次全量下载与当前画面的按需请求都不会问它。
- **旧版 `images/manual/` 缓存不再被遗漏**：卡图统计同时计入当前缓存与旧版 manual 目录，
  「清理卡图」两处都清——只删 PNG，卡牌数据库、设置与其他文件原样保留。
- **准确的最终统计**：批处理运行中显示 已完成/总数、失败与无卡图数量；完成后显示
  成功下载、失败、无卡图与已有缓存的最终汇总。

## Verification / 验证

- Python: 229 tests pass, including new cases for retry-then-success counting, HTTP 404
  handling without retries, the 100% progress bound, and legacy manual-directory
  statistics and cleanup that preserve JSON databases and unrelated files.
- Frontend: type check, build and panel checks pass; both interface dictionaries carry
  the same keys (74), including the new batch summary strings.
- Native: HUD state tests pass locally and in CI; the Linux renderer (Ubuntu 20.04,
  glibc 2.31), ZIP packaging and packaged-module import check are built by this workflow.

## Install / 安装

Download `hearthstone-hud-0.7.2.zip` and install it from Decky Loader
(**Settings → General → Install plugin from file**). Upgrading keeps settings, caches
and card art. Linux x86_64 (SteamOS) only.

下载 `hearthstone-hud-0.7.2.zip`，在 Decky Loader 中通过「从文件安装插件」选择该 ZIP。
覆盖升级会保留设置、缓存与卡图。仅支持 Linux x86_64（SteamOS）。
