# Hearthstone HUD v1.0.1

A small maintenance release right after v1.0.0: message clean-up and one interaction fix.
No new features. v1.0.0 之后的第一个小维护版本：文案清理与一处交互修复，无新功能。

## Fixes / 修复

- **Download-failure messages match the current features.** The texts no longer mention the
  offline import that was removed: a failed download points to the *Retry card data
  download* button, card-data validation messages describe downloaded data instead of
  imported files, and the missing-CA TLS error now suggests reinstalling the full plugin
  ZIP.
  **下载失败提示与现有功能一致**：文案不再提及已移除的离线导入——下载失败指向「重试下载
  卡牌数据」按钮，卡牌数据校验信息改为描述下载数据，缺少 CA 证书时提示重新安装完整插件 ZIP。
- **No button conflict during a full art download.** While the batch runs, both
  *Download all card art* and *Delete card art* are disabled until it completes.
  **全量下载卡图期间不冲突**：批处理运行中，「下载全部卡图」与「清理卡图」同时禁用。
- **The language table is untouched.** The engine still knows all fourteen HearthstoneJSON
  locales; the settings page continues to manage the English (enUS) and Simplified Chinese
  (zhCN) databases, which follow the interface language.
  **语言体系不变**：引擎仍保留全部 14 种 HearthstoneJSON 语言；设置页继续管理跟随界面
  语言的英文（enUS）与简体中文（zhCN）数据库。

## Verification / 验证

- Python: 223 unit tests pass; frontend type check, build and panel checks pass; native
  HUD state tests and the Ubuntu 20.04 renderer build, ZIP packaging and packaged-module
  import check run in CI.

## Install / 安装

Stable address, always the newest version:
固定地址，始终为最新稳定版：

```
https://github.com/ohxiaoguang/hearthstone-hud/releases/latest/download/hearthstone-hud.zip
```

Or grab `hearthstone-hud.zip` from this release page, then in Decky Loader open
**Settings (⚙) → General → Install plugin from file** and pick the ZIP. Upgrading keeps
settings, caches and card art.

或在本 Release 页面下载 `hearthstone-hud.zip`，在 Decky Loader 中打开
**设置（⚙）→ 通用 → 从文件安装插件** 选择该 ZIP。覆盖升级保留设置、缓存与卡图。
