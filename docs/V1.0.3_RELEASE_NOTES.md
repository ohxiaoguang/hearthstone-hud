# Hearthstone HUD v1.0.3

## Changes / 更新内容

- Add **Copy Update Link** next to **Copy diagnostics**. Both buttons keep the
  existing style and share one row. The new button reuses the clipboard helper
  with localized success/failure feedback and copies the fixed latest-stable ZIP URL.
  在“复制诊断”旁新增“复制更新链接”，保持现有按钮样式并同排显示，复用剪贴板逻辑，提供中英文反馈。
- Add 200 ms full-card hover previews, localized render downloads with English
  fallback, background download/decode, and bounded separate disk/texture caches.
  新增完整卡面悬停预览，支持语言回退、后台下载与解码、独立容量受限缓存。
- Clear arena selections after confirmed exit; retain valid data on temporary read errors.
  明确退出竞技场选牌后清理旧状态，临时读取异常时保留有效数据。
- Show a waiting-for-match hint at the remaining-deck position and use the deck name
  associated with the current match's Decks.log definition; retain added/transformed groups.
  新增右侧空闲提示，显示本局真实卡组名称，保留新增／变形分类。

## Validation / 验证

Targeted Python regression tests and source checks passed during development.
The new button has been source-checked for its fixed URL, shared-row layout,
clipboard helper and bilingual feedback. No local build or packaging was performed
for this release request; the GitHub Actions tag workflow builds, tests and packages
on Linux before publishing the release. Live SteamOS hover/input verification remains pending.

已执行针对性 Python 回归与源码检查。本次未在本地构建或打包；tag 触发 GitHub Actions
在 Linux 上完成测试、构建、打包和发布。SteamOS 实机悬停与输入兼容性尚待验证。
