# Hearthstone HUD v1.0.13

## 奥秘候选提示

对手挂有奥秘时，HUD 会显示当前数量。日志已揭示的奥秘显示具体卡牌，未知奥秘共享一份职业候选列表。列表合并重复印刷版本，包含历史奥秘，并标注“未按模式合法卡池过滤”。

“奥秘提示”在 Decky 设置中默认开启。中途加入对局时，HUD 会从已有日志恢复奥秘状态。支持中英文卡名、卡图和悬停大图。最后一个奥秘离场或对局结束后，面板自动隐藏。

## Opponent Secret hints

The HUD shows how many Secrets the opponent has in play. It displays the card when the log reveals its identity. Unknown Secrets share a candidate list for the opponent’s class. The list groups duplicate printings and includes historical Secrets. A notice indicates that the list is unfiltered for format legality.

Secret hints are on by default in Decky settings. The HUD can recover active Secrets from the existing log when opened mid-match. Cards use the selected English or Chinese names, artwork and hover previews. The panel closes when the last Secret leaves play or the match ends.
