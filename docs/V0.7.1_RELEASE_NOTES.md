# Hearthstone HUD v0.7.1

Release hardening for v0.7.0's multi-language support. No new features.
v0.7.0 多语言支持的发版加固，无新功能。

## Fixes / 修复

- **Card language switching is race-free.** Picking a new language while a download is still
  running now discards that download: a late payload can no longer be installed as the new
  language or clear its pending state. Switching back to a language that is already cached
  still downloads nothing.
- **No request storm.** A failing download keeps the original retry spacing (a minute without
  data, an hour with data) instead of being retried by every worker tick.
- **The HUD is fully translated.** The deck group headings (original deck / added or
  transformed) were the last strings hardcoded in the renderer; they now arrive from the
  backend, with English fallbacks for older state files.
- **Settings errors are bilingual.** Plugin, setting-validation, log-configuration, HUD
  start/stop and Gamescope messages all come from the translation catalog, so English mode
  shows English errors and Chinese mode shows Chinese ones.
- **Switching is immediate.** No plugin restart is needed; the panel and the HUD both follow
  the new language on the next publish.

- **卡牌语言切换不再有竞态**：下载途中切换语言会作废这次下载，迟到的数据不会装成新语言，也不会
  清除新语言的待下载状态；切回已有缓存的语言仍然不联网。
- **不会反复重试**：下载失败保持原有退避（无数据 1 分钟、有数据 1 小时），不再每个循环都请求。
- **HUD 文案全部翻译**：牌库分组标题（原始牌库 / 后加入·变形）改为后端下发，旧 state.json 有英文回退。
- **设置界面错误双语**：插件、配置校验、日志配置、HUD 启停、Gamescope 信息全部来自翻译字典。
- **切换立即生效**：无需重启插件，面板与 HUD 在下一次发布时更新。

## Verification / 验证

- Python: 215 tests pass, including new cases for switching mid-download, a late payload from
  another locale, rapid switching, stale generations, retry spacing, and an assertion that
  English output contains no Chinese in the HUD, the published state or the panel.
- Frontend: type check, build, clipboard and fold checks, and both interface dictionaries
  verified to carry the same keys.
- Native: HUD state tests pass locally and in CI; Linux renderer (Ubuntu 20.04, glibc 2.31),
  ZIP packaging and packaged-module import check are built by this workflow.

## Install / 安装

Download `hearthstone-hud-0.7.1.zip` and install it from Decky Loader
(**Settings → General → Install plugin from file**). Upgrading keeps settings, caches and
card art. Linux x86_64 (SteamOS) only.

下载 `hearthstone-hud-0.7.1.zip`，在 Decky Loader 中通过「从文件安装插件」选择该 ZIP。覆盖升级
会保留设置、缓存与卡图。仅支持 Linux x86_64（SteamOS）。
