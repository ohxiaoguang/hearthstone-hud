# Hearthstone HUD v0.7.0

Card data in all 14 HearthstoneJSON languages, plus a bilingual interface.
卡牌数据支持全部 14 种语言，界面支持中英双语。

## Highlights / 主要变化

- **14 card languages** — `enUS`, `zhCN`, `zhTW`, `deDE`, `esES`, `esMX`, `frFR`, `itIT`,
  `jaJP`, `koKR`, `plPL`, `ptBR`, `ruRU`, `thTH`. Every language has its own cache file, so
  switching back and forth never downloads the same data twice.
  卡牌数据库支持全部 14 种语言，每种语言独立缓存，来回切换不会重复下载。
- **Interface language** — English (default) or Simplified Chinese, independent from the card
  language. Covers the Decky panel, all HUD labels and the arena titles.
  界面语言可选英文（默认）或简体中文，与卡牌语言分开设置，覆盖 Decky 面板、HUD 文案与竞技场标题。
- **Font coverage** — the HUD atlas now includes Latin, Cyrillic, Chinese, Japanese, Korean and
  Thai (64 MB, unchanged from the previous CJK-only atlas).
  字体图集覆盖拉丁、西里尔、中日韩与泰文，内存占用仍为 64 MB。
- **Renamed setting** — `chinese_names` became `show_card_names`; existing values are migrated
  automatically.
- **Docs** — README rewritten as a user guide (English + 简体中文); outdated development
  reports removed; third-party credits and data sources consolidated in `licenses/THIRD_PARTY.md`
  and the README.

## Verification / 验证

- Python: 205 tests pass (`python3 -m unittest discover -s tests`), including 17 new language
  tests (catalog parity, per-locale caches, switching without downloads, settings migration).
- Frontend: type check, build, clipboard and fold checks, plus a check that both interface
  dictionaries carry the same keys.
- Native: HUD state validation incl. localized labels and the `Selected X/30` title;
  font atlas measured at 33216 glyphs / 4096×4096 (64 MB).
- Linux renderer (Ubuntu 20.04, glibc 2.31) and plugin packaging are built by this workflow.

## Install / 安装

Download `hearthstone-hud-0.7.0.zip` and install it from Decky Loader
(**Settings → General → Install plugin from file**). Upgrading over an older version keeps
your settings and caches. Linux x86_64 (SteamOS) only.

下载 `hearthstone-hud-0.7.0.zip`，在 Decky Loader 中通过「从文件安装插件」选择该 ZIP。覆盖旧版本
升级会保留设置与缓存。仅支持 Linux x86_64（SteamOS）。
