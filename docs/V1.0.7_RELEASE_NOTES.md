# Hearthstone HUD v1.0.7

## Changes / 更新内容

- Add a dark frame to hover previews, with a same-sized loading placeholder,
  localized status text and an animated indicator. Use 256px complete card renders
  (normally 256x384) while preserving card proportions and edge avoidance.
  预览新增背景框和同尺寸加载占位，使用较小的完整卡面，保持比例与边缘避让。
- Separate Card thumbnails from Full card renders in Download resources. Full cards
  have cache count/size, download-all, cancel, retry progress and inline-confirmed clear.
  下载资源明确区分缩略图与完整卡面，完整卡面提供数量、占用、下载、取消、重试进度与确认清理。
- Store both hover and bulk downloads in
  `cache/full-cards/256x/<locale>/<CardID>.png`. No manual/automatic split, disk quota
  or automatic disk eviction. Images remain until the user clears them.
  按需与全量下载统一目录、共用文件，不再区分 manual/automatic；无磁盘容量限制和自动淘汰。
- Hover requests use a high-priority queue and share pending reservations with the
  background bulk queue. Existing files are skipped; transient batch failures retry
  once; unavailable renders are counted separately. Cancellation keeps downloaded
  files and does not cancel promoted hover requests. Language changes cancel the batch.
  悬停优先并跨队列去重，已有文件跳过、临时失败重试一次、无资源单独计数；取消保留已有文件，
  不影响提升为悬停请求的任务，切换语言取消当前批量任务。
- Merge legacy manual PNGs in the background. Prefer valid unified copies; otherwise
  atomically move verified source files into place. Delete old sources only after a
  verified copy exists, and remove only empty old directories. Preserve/report failed
  migrations for retry after restart. Clearing full cards invalidates their GL cache.
  后台安全迁移旧 manual 图片，验证后合并，只删除已确认副本和空目录；失败保留并诊断，重启可重试。
  清理完整卡面同步失效对应显存缓存。
- Keep thumbnail resource management, image source and X11 click-through unchanged.
  Full-card texture memory still holds at most 12 textures; this never deletes disk files.
  缩略图管理、卡面来源与点击穿透不变，完整卡面最多保留 12 张纹理，不删除磁盘图片。
