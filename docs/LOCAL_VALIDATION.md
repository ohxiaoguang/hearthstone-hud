# v0.2.3 本地验证与构建边界

用户已要求停止本机交叉编译准备，后续 Linux 原生编译统一交给 GitHub Actions；随后明确授权提交、推送并通过 Actions 发布。已清理临时工具链、sysroot 和交叉构建目录，保留代码与测试记录。没有安装 Homebrew 软件包，没有修改全局环境变量、Xcode、Clang 或 SDK 配置。

## 已完成的功能代码

- 逐卡统计数量可信度，分开初始数量、当前剩余和已知在库数量。完整实体证据可以保留准确数量；仅有正数下限才显示 >=n，否则未知显示 ?。未知原始实体只影响仍可能属于该卡的未确定副本。未知生成牌若可能是任意身份，仍会合理影响相关数量，不能强行宣称准确。
- 卡图主动下载复用后台队列，去重、限并发、进度及成功/失败/跳过计数；失败允许主动重试，自动请求保留冷却时间。
- 256x59 PNG 校验覆盖文件头、CRC、尺寸、受限解压和完整性。ZIP 导入限制路径、ID、数量、单图/总大小和压缩比，使用原子写入；images/manual 优先，自动清理不进入手动目录。
- 结构化诊断复制、有界错误摘要、常见敏感字段脱敏、剪贴板失败的可选择文本备用。没有 TXT 导出或 Downloads 输出逻辑。
- Decky 面板分组、折叠与紧凑布局。原生侧仅调整数量文字与允许读取手动图片目录，窗口协议、焦点、触控属性和分页公式未改。
