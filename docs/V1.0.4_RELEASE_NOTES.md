# Hearthstone HUD v1.0.4

## Hover preview fixes / 悬停预览修复

- Query the X11 root pointer, translate it to the overlay client, then map it into
  ImGui display coordinates. Arena and match card rows share the same clipped hit regions.
  从 X11 根窗口获取鼠标，转换到 HUD 客户区和 ImGui 坐标；竞技场与对战共用命中逻辑。
- Include hover pipeline details in Copy diagnostics: pointer query/translation,
  visible card regions, hit/dwell state, hover.json handoff, download source/errors,
  PNG decode, GL upload and rendering failures.
  复制诊断可区分鼠标检测、未命中、IPC、下载、解码、纹理上传和渲染阶段故障。
- Retry failed downloads after a 60-second cooldown even while hovering the same
  card. Invalid request objects and timestamps are reported without stopping tracking.
  持续悬停同一卡牌时，下载失败冷却 60 秒后重试；异常请求不会阻断记牌。
- Preserve the full-screen transparent window, empty X11 input shape and ImGui
  NoInputs flags. No mouse polling thread or input-capturing window is added.
  保留透明全屏窗口与点击穿透，不新增鼠标轮询线程或拦截输入窗口。

## Validation / 验证

14 targeted Python tests passed, including download retries, malformed requests,
clipboard diagnostics and backend lifecycle checks. Native coordinate and boundary
regression cases were added for CI. No local build, packaging or build-environment
installation was performed. Linux/SteamOS live hover and compositor visibility remain
unverified. GitHub Actions builds, tests and packages the tagged release.

14 项针对性 Python 测试通过，已补充原生坐标和边界测试供 CI 执行。
未在本地构建、打包或安装构建环境；Linux/SteamOS 实机悬停及合成器可见性尚待验证。
