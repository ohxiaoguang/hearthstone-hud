# Hearthstone HUD v1.0.5

## Hover diagnostics / 悬停诊断增强

This release helps locate the reported hover failure; it does not claim that live
hover previews are fixed. The supplied v1.0.4 arena diagnostic registered all seven
card regions but sampled the pointer at the bottom-right corner, outside the cards.
本版本用于定位悬停问题，不宣称已修复实机故障。提供的 v1.0.4 竞技场诊断已注册全部
7 个卡牌区域，但采样指针在屏幕右下角，未命中卡牌。

- Use one explicit frame-local card-region collector for arena and match panels.
  Report input/submitted/registered counts, ID rejection, clipping, sample Card IDs,
  draw rectangles and clip rectangles.
  各面板共用当前帧收集器，诊断记录卡牌行数、注册数、过滤原因、Card ID 与矩形范围。
- Retain bounded snapshots of the last nonempty registration, last hover hit and
  last image request after opening Decky or ending a match.
  打开 Decky 或结束对局后，仍保留最近非空注册、命中和图片请求的有限历史快照。
- Count pointer samples and position changes while cards are registered; report
  observed bounds, time since the last change, and game/renderer X11 displays.
  记录有卡牌时的指针位置变化、范围、距上次变化的时间，以及游戏与 HUD 的 X11 Display。
- Keep existing pointer acquisition, image download/cache logic and X11 click-through.
  保留现有鼠标获取、图片下载／缓存与 X11 点击穿透。

## Verification / 验证

14 targeted Python tests pass, covering diagnostic retention, safe display metadata,
image requests, cancellation and retry behavior. Native registration, hit boundaries,
frame isolation and pointer-history regression cases were added for CI. No local
build, packaging or build-environment installation was performed. Linux/SteamOS
live hover remains unverified; tagged builds and packaging run in GitHub Actions.

14 项针对性 Python 测试通过；已补充原生注册、命中边界、帧隔离和指针历史测试供 CI 执行。
未在本地构建、打包或安装构建环境，实机悬停问题仍待验证。

## Reproduction / 复测

With HUD card rows visible, move across three HUD cards, dwelling about two seconds
on each. Then open Decky and copy diagnostics. The retained snapshots and pointer
history distinguish no registration, no hit, a stationary pointer sample and a request
that reached the image pipeline.

在 HUD 显示卡牌时，依次移过三张 HUD 卡牌，每张停留约两秒，再打开 Decky 复制诊断。
历史快照和指针移动记录可区分未注册、未命中、指针采样不变和图片链路已触发。
