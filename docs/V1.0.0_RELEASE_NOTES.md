# Hearthstone HUD v1.0.0

The first stable release. Hearthstone HUD is a Decky Loader plugin for SteamOS and Linux
that overlays a deck tracker on Hearthstone under Proton/Gamescope, with an opt-in arena
helper — read-only, local-only, no game modification.

Hearthstone HUD 的第一个正式稳定版本。这是一个 Decky Loader 插件，在 Proton/Gamescope 下
运行的《炉石传说》上叠加记牌悬浮层，并提供可选的竞技场辅助——全程只读、纯本地，不修改游戏。

## Features / 功能

- **Deck tracking / 对局记牌** — Live remaining deck from Power.log, grouped by original
  versus added/transformed cards; opponent hand and deck counts; both players' recent
  plays with per-card provenance (starting deck, transformed, copied, generated); turn
  header; exact counts with a stated reason whenever the evidence is incomplete.
  Decks.log supplies the exact starting deck for arena matches.
  实时己方剩余牌库（原始牌 / 后加入·变形分组）、对手手牌与牌库数量、双方最近出牌与每张
  牌的来源（初始牌、变形、复制、效果生成）、回合信息；证据不足时给出原因。Decks.log 提供
  竞技场对局的完整初始牌组。
- **Arena helper / 竞技场辅助** — Opt-in read-only process memory access: hero and card
  candidates with HearthArena card ratings and Firestone class statistics; the selected
  deck sorted by mana cost (ties by name, unknown cost last); duplicates kept as real
  copies. The game's DraftDeck is the only source for selected cards, verified by two
  consistent reads; candidates are preview-only. A failed read keeps the last deck marked
  「份数待确认 / count unconfirmed」.
  可选的只读内存读取：英雄与卡牌候选（HearthArena 评分 + Firestone 职业统计）、已选牌按
  费用升序（同费按名称、未知费用垫底）、重复卡保留实际份数。已选牌唯一来源是内存
  DraftDeck，经两次一致性读取校验；候选仅供预览。
- **Languages / 语言** — English (default) and 简体中文 interface; the card database
  follows the interface language (enUS / zhCN) with a per-language cache, offline reuse
  and download only when missing. Race-free switching: a download in flight is discarded
  when you pick another language.
  英文（默认）/ 简体中文界面；卡牌数据库跟随界面语言并按语言独立缓存，离线复用、缺失才
  下载；下载途中切换语言不会造成数据错乱。
- **Card art / 卡图** — Language-independent tile cache, on demand or one resumable full
  download, with accurate per-card statistics (success, failed, without art, already
  cached); HTTP 404 is remembered as "no art" and never retried in the session.
  与语言无关的卡图缓存：按需或一次可断点续传的全量下载，统计成功/失败/无卡图/已有缓存；
  HTTP 404 记为「无卡图」，本次会话不再请求。
- **Resource management / 资源管理** — Per-database size, state and delete; card art usage
  with independent cleanup. Clearing one resource never touches the others.
  每个数据库的大小、状态与删除按钮；卡图用量与独立清理；互不影响。
- **Safety / 安全性** — Read-only access to the game; a master switch that stops every
  background worker; bounded, CRC-validated downloads; log.config management that never
  overwrites unrelated sections; one-click redacted diagnostics.
  对游戏只读；总开关停止全部后台任务；下载有大小与 CRC 校验；log.config 不覆盖无关配置；
  一键复制脱敏诊断。

## Known limitations / 已知限制

- Linux x86_64 (SteamOS / Gamescope) only; no Windows build.
  仅支持 Linux x86_64（SteamOS / Gamescope），无 Windows 版本。
- The arena helper needs the game process; if memory cannot be read, the arena panel shows
  the last deck as unconfirmed instead of guessing.
  竞技场辅助依赖游戏进程；内存不可用时显示上一份牌组并标注待确认，不做猜测。
- Interface languages beyond English / 简体中文 are not provided yet; the engine already
  understands all fourteen HearthstoneJSON card locales for future expansion.
  暂只提供英文与简体中文界面；引擎已支持全部 14 种 HearthstoneJSON 卡牌语言以便扩展。

## Verification / 验证

- Python: 229 unit tests pass (tracking, arena, memory, language, resources, packaging).
- Frontend: TypeScript type check, build, and panel checks; both interface dictionaries
  carry the same keys.
- Native: HUD state tests and the Linux renderer (Ubuntu 20.04, glibc 2.31) build in CI;
  ZIP packaging and packaged-module import check run on every build.

## Install / 安装

Stable address, always the newest version:
固定地址，始终为最新稳定版：

```
https://github.com/ohxiaoguang/hearthstone-hud/releases/latest/download/hearthstone-hud.zip
```

Or grab `hearthstone-hud.zip` from this release page, then in Decky Loader open
**Settings (⚙) → General → Install plugin from file** and pick the ZIP. Upgrading keeps
settings, caches and card art.

或在本 Release 页面下载 `hearthstone-hud.zip`，在 Decky Loader 中打开
**设置（⚙）→ 通用 → 从文件安装插件** 选择该 ZIP。覆盖升级保留设置、缓存与卡图。
