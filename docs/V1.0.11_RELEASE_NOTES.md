# Hearthstone HUD v1.0.11

## 地下竞技场 · SteamOS

- 修复补选后游戏提前切换模式、HUD 在移除途中显示「等待对局开始」的问题。
- 确认完整的 35 张牌组后，右侧列表随实际移除更新。如果选牌界面消失，HUD 会继续核验同一牌组。剩余 30 张时清除建议移除标记。
- 诊断报告新增游戏原始模式、槽位、快照牌数、选牌界面是否存在及最近一次阶段转换，便于排查实机行为。

## Underground Arena on SteamOS

- Fixed the HUD returning to the waiting screen when the game changed modes during card removal.
- Once the 35-card pool is confirmed, the deck panel updates after each cut. If the draft display disappears, the HUD continues checking the same deck. The highlights clear when 30 cards remain.
- Arena diagnostics now show the raw mode, slot, snapshot count, display presence and last phase transition.
