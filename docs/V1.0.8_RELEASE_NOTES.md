# Hearthstone HUD v1.0.8

## Preview spacing and size / 预览边距与大小

- Trim only fully transparent outer PNG canvas during background decode. Preserve
  every nonzero-alpha pixel, including mana crystals, shadows and decorative glows,
  with one source pixel of guard. Cached source files and downloads are unchanged.
  后台解码仅裁去完全透明的外缘，保留所有非零透明度像素和一像素保护边，不修改缓存原图和下载流程。
- Reduce frame padding from 8px to 2px at the base scale, allowing the visible card
  to fill the frame more closely while preserving proportions.
  背景框基础边距从 8px 缩为 2px，使可见卡面更贴近外框，保持原始比例。
- Add Full card preview scale to Display settings: 0.5–2.0, default 1.0. It applies
  on top of overall HUD scale and affects preview images/loading frames only;
  card rows and panel sizes are unchanged. Oversized previews still fit the screen.
  显示设置新增“完整卡面预览缩放”，在整体缩放基础上单独调整预览和加载框，不影响列表，过大时按屏幕空间收缩。
- Fit loading text to narrow previews and report preview_scale, source_size and
  visible_size in diagnostics. Use owned pixel buffers during decode for safe cleanup.
  小尺寸加载文字适配宽度，诊断显示预览缩放、原始和可见尺寸，解码缓冲自动回收。

## Validation / 验证

28 targeted Python tests passed, including setting defaults, invalid value rejection,
persistence, state propagation and independence from card-row settings. Bilingual
catalog and preview-slider wiring source checks passed. Native alpha-bound/layout/
state regression cases are included for CI; no local build or packaging was performed.
Live SteamOS validation of the new crop/layout remains pending. GitHub Actions builds,
tests and packages this tagged release.

28 项针对性 Python 测试及中英文滑块接线检查通过，已补充原生透明边裁剪、布局与状态测试供 CI 执行。
未在本地构建或打包，新裁边和布局仍需 SteamOS 实机验证。
